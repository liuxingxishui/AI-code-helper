# 2026-10-20

- 从零搭建《AI 编程小助手》前端项目（Vue3 + Vite + Axios）：单页聊天室，自动生成 memoryId，通过 SSE 调用后端 `GET /api/ai/chat?memoryId&message`（Spring `Flux<ServerSentEvent<String>>`）。
- 关键决策：SSE 流式读取用 fetch ReadableStream 实现（浏览器端 Axios 不支持增量解析流式响应）；Axios 实例保留在 `src/api/chat.js` 供普通请求使用。Vite 代理 `/api` → `http://localhost:8081` 解决跨域。
- 文件：package.json / vite.config.js / index.html / src/main.js / src/App.vue / src/api/chat.js。构建通过，dev 服务器运行于 5173 端口。
- 排查后端启动日志：① 接口 404 根因是 AiController.chat 漏了 @GetMapping("/chat")，已补上并加 produces=text/event-stream（需重启后端生效）；② 日志中每分钟一次的 MCP "SSE channel failure" 是 langchain4j HttpMcpTransport 连 bigmodel.cn 的 60s 读超时+自动重连，属良性噪音；③ mvnw 命令行编译失败是因 JAVA_HOME 指向 JDK 1.8（不支持文本块语法），顺带在 pom.xml 补了 UTF-8 编码配置，用 JDK 25 编译验证 BUILD SUCCESS。
- 重启后验证：SSE 接口已通（curl 实测逐字流式返回）。在 application.yml 加了 logging.level 将 SseEventListener 调为 ERROR 屏蔽 MCP 重连刷屏。后端大模型为 kimi-k2.6（Moonshot），embedding 用智谱 embedding-3，MCP 联网搜索用智谱 web_search。
- 前端 UI 调整：输入区与消息区同宽（900px 居中）；发送按钮改为圆形纸飞机图标并移入输入框内右端（right:5px）；输入框 border-radius 最终定为 50px 胶囊形。
- 部署验证：前端 `npm run build` 产物 dist 正常；后端 `mvnw clean package -DskipTests`（需 JAVA_HOME=jdk-25）产出 target/AI-code-helper-0.0.1-SNAPSHOT.jar（33MB）。给出服务器上线方案：Nginx 托管 dist + 反代 /api 到 8081（SSE 需 proxy_buffering off），后端 jar 用 systemd 守护，需 KIMI_KEY/GLM_KEY 环境变量与 JDK 21+。
